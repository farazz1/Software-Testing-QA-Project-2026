31/05/2026, 7:04 pm - M. Ibrahim Siddiqui IBA 27: Inconsistencies I found while testing are as follows:
* Staff and admin roles have been merged into the admin role only
* Cannot explicitly create new staff and admin roles. All new roles are USER roles initially, and existing admin can convert them into new admins
* Admin doesn't have a menu dashboard, and therefore cannot access or alter the present menu items
* When booking an event, customer cannot select the menu or catering, only submit a request for booking said event. 
* Additionally, once customer submits the request, there is no way for customer to view said request's status, whether it be pending, confirmed, or rejected. Nor can they even check their request history. 
* There is no upper bound limit when booking/ requesting events. There's only a lower bound check of GTE 5.
* When logged in as customer, you can manually change the URL to admin page and access all admin capabilities. When you go back to home page, you are still logged in as said customer. 
* Reservation is limited to one table per booking, cannot book multiple tables in a single reservation, if number of people exceed table size.
